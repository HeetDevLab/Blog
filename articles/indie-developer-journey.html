My Journey as an Indie Developer

HeetDevLabIndependent developer notes
HeetDevLab started as a learning experiment. As a student exploring Android development and software building, the goal was simple — build something meaningful.

Starting From Scratch

Learning programming fundamentals, experimenting with projects and gradually understanding software development built the foundation.

Building HeetDevLab

The idea was to create useful digital tools with a focus on privacy and independence. From WebTools to Sentinex, each project has been an opportunity to learn by building.

Challenges Faced

Balancing studies, learning new technologies and building projects requires consistency, patience and realistic goals.

Lessons Learned

Consistency beats motivation. Shipping small, useful improvements regularly creates progress that can be measured.

Future Vision

The goal is to keep learning, improve existing products and build more useful software over time.
